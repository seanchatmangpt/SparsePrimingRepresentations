# SPR — Recursive Abstraction

- An abstraction becomes recursive when the machinery used to describe a level is itself representable by the same abstraction.
- Recursive abstraction compresses families of systems, not just repeated syntax.
- A generator can generate generators when generator structure is itself admitted data.
- An ontology can describe ontologies when vocabulary structure is represented explicitly.
- A workflow can manufacture workflows when route semantics are first-class objects.
- Recursion should preserve the same admission, authority, and verification invariants at every level.
- Meta-level power does not imply meta-level ambient authority.
- Self-description without bounded evaluation invites uncontrolled reflection.
- The useful fixed point is a small kernel whose rules can reproduce larger lawful structures.
- Recursive systems should expose a base case, a composition rule, a termination or convergence condition, and a falsifier.
- Each recursive layer should reduce net duplication or coordination cost; otherwise recursion is decorative complexity.
- The strongest recursive abstraction makes extensions look like data while keeping execution consequences explicit.
