# SPR — Learning Production System

- A production system can manufacture learning rather than only finished deployable artifacts.
- In exploration, an experiment that falsifies a hypothesis can be successful production when the learning is captured durably.
- Build failure is not automatically product failure; it may reveal a dependency, environment, interface, or assumption boundary.
- The unit of value is reusable reduction of uncertainty.
- Toyota Production System principles still apply: expose defects, reduce waiting, limit hidden work, standardize useful learning, and improve the process.
- FMEA turns recurring failure possibilities into explicit prevention and detection controls.
- RCA locates the failed transition rather than blaming the final symptom.
- DfLSS moves discovered requirements and failure modes upstream into design.
- A learning cell should convert every meaningful failure into a guard, fixture, test, schema, theorem, refusal rule, or documented exclusion when possible.
- Repeating the same unchanged failure without a new hypothesis is waste.
- Partial execution can have standing as PARTIAL_ALIVE while still producing valuable knowledge.
- The system is unsuccessful only when it fails to manufacture either verified capability or durable learning from the available work.
